1. 先备份未来回滚当时的代码和数据库；确认当前 schema、数据结构、依赖与本版本兼容。
2. 在本地或独立代码目录获取并验证标签：

   ```sh
   git fetch origin --tags
   git cat-file -t v1.0.0-rc.1
   git show --no-patch v1.0.0-rc.1
   git rev-parse 'v1.0.0-rc.1^{commit}'
   git worktree add --detach ../photo-ring-rc1-rollback v1.0.0-rc.1
   ```

   `cat-file -t` 应为 tag；最终 commit 应与服务器 release-seal.json 记录一致。目标新目录须不存在。不要 force push、移动标签或 reset 覆盖未提交工作。
