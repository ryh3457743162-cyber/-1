## 照片回收站 v1

## 书本封面 v1

- 独立 `data/book-cover.json`，无配置时返回默认封面，不插入 BookPage。

- 正文第一页仍为 `01 / 26`；既有 pageId、排序和页码未变。

## 联合兼容

- 封面照片进入回收站：保留 photoId，公开封面降级纯文字；选择器排除回收站照片。

- 永久删除：封面 photoId 置空，文字保留；正文 slot 和精选 comment 引用安全清理，页面保留。
- 迁移保留已有 `hiddenSeedIds`，不将历史隐藏照片意外恢复。

项目实际采用 JSON 元数据文件，不是 SQL/ORM 数据库。

5. 启动原有 systemd/Gunicorn 服务并检查健康状态。

## 回滚

### 代码

确认 `git show v1.1.0` 和部署记录。需要回到发布前时使用 `pre-trash-cover-production-20260929` / `8b690d2` 对应代码，先备份当前状态，再按既有部署方式更新；不要在运行中随意 checkout。rc.1/rc.2 标签仍可追溯，但最近生产基线包含后续 ICP 修复，应优先使用本次 predeploy marker。

### 数据

无自动 downgrade。必须先检查旧代码对新增 JSON 字段、cover 配置及回收站状态的兼容性。必要时停止应用写入，恢复上述一致性备份的元数据，再启动匹配的稳定代码。不能只回滚代码，让回收站中的照片因旧查询重新公开；也不能盲目覆盖发布后真实新增内容。

### OSS

manifest 只记录资源，不是对象备份。正常代码回滚不删除 OSS。已经永久删除的对象无法通过恢复 JSON 找回；本次只永久删除明确的测试对象，没有删除真实纪念照片。没有自动清理任务。
