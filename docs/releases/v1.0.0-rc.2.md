## 修复范围

与 rc.1 相比，业务修改只有两个文件：

- `public/index.html`：音乐 slider 或其他交互控件获得焦点时，书本全局导航方向键提前返回，保留控件原生键盘行为；普通区域仍可方向键翻书。
- `public/book-admin.html`：限定布局标题 span 的 CSS 选择器，避免覆盖 `.layout-mini` 的 grid；照片库设置内容高度网格行和起始对齐，避免卡片高度被压缩。

解决的问题：

- P2：音乐 slider 键盘方向键不再触发书本翻页。
- P3：书本后台模板示意恢复正常。
- P3：书本后台照片库卡片裁切问题修复。

没有修改评论、音乐播放、照片 OSS、书本数据或前台布局算法。
