## 新增功能

- 照片管理卡片增加「编辑信息」弹窗；管理员修改照片名称与实际拍摄日期。
- 缩略图与上传时间只读。名称去除首尾空格，限制 1–60 字符；保存时显示 Loading，失败保留输入。
- 新增可选 `shotDate`：纯日期 `YYYY-MM-DD` 或 `null`，不进行 UTC 时区换算；可清空未知日期。
- 实际持久化为 JSON。复用 `title`、`uploaded`；上传照片保存于既有 `photos` 记录，历史内置照片的覆盖值保存于既有 `seedStates`。
- 缺少 `shotDate` 的旧记录保持兼容，按未知日期展示。无需 migration，不批量改写历史数据。
- 新增 `PATCH /api/manage/photos/<photo_id>`，复用管理员 Session 鉴权。只接受 `title`、`shotDate`，后端校验名称、真实日期与字段白名单；非管理员返回 401，回收站照片返回 409。
- 新增 `/photo-metadata.js` Flask 静态脚本路由，与脚本一同部署。

## 前台同步与数据安全

- 图集、平面、照片详情及使用照片元数据的位置读取最新名称、日期。
- 图集/平面按拍摄日期年份分组，日期未知时使用原归档 `year`；已知日期按时间正序，未知日期保留原相对顺序。
- 原 `year`、上传时间、photoId、objectKey、thumbnailKey 均不改变。
- 书本继续使用原归档年份及手动 pageId/order/slot，不随拍摄日期重新排版。封面、评论审核、精选留言、回收站关系保持。
- 同一浏览器使用 storage 通知并在切回页面时刷新元数据；没有高频轮询。不同浏览器已经打开的页面需刷新或重新进入以读取最新值。
- 复用照片生命周期跨进程锁及临时文件、fsync、原子替换，相关照片管理操作在锁内读取最新数据后写入。生产 Linux 使用 flock。
- 更新不重建全局 audio。无需修改 OSS、EXIF、原图、缩略图、nginx、HTTPS 或环境变量。
