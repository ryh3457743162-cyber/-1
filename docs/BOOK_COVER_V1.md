# 书本封面 v1（本地开发）

日期：2026-09-29。开发分支：`feature/book-cover`。
基线：当前稳定维护代码 `8b690d200327abfcc99512d98735f4e73ee1926e`，包含移动端 ICP Footer 修复。没有合并照片回收站分支。

## 数据与 API

封面独立保存为 `data/book-cover.json`，不向 `book-layout.json` 插入页，不修改照片、评论或音乐数据。
未配置时直接返回默认封面；首次保存时才创建配置文件，无 SQL 表、schema 变更或 migration。

字段：`title`（最多 120 字）、`subtitle`（200）、`dateText`（80）、`footerText`（300）、`photoId`（字符串或 null）、`layout`、`titleAlign`、`photoPosition`、`showPhoto`、服务器生成的 `updatedAt`。
四种文字均可留空，输入去除首尾空格。

- `GET /api/book-cover`：公开封面及可用照片的安全 URL；不返回 OSS key、凭证或管理时间字段。
- `GET /api/manage/book-cover`：管理员读取配置。
- `PUT /api/manage/book-cover`：管理员独立保存配置；复用现有会话鉴权。

配置写入采用跨进程文件锁、临时文件、fsync 和原子替换。无效输入或写入失败保留原配置。

## 编辑与展示

`/admin/book` 增加“封面设置 / 正文排版”切换。封面表单和实时预览使用共享渲染脚本，选择照片复用现有照片库。
仅点击“保存封面”写入封面配置；“保存排版”仍只保存原正文配置。两种未保存状态独立。

模板：经典纪念册、照片主视觉、极简文字、相纸纪念风。
标题可左 / 中 / 右对齐，照片可上 / 中 / 下放置。极简模板不加载照片，但保留所选 photoId 以便切回其他模板。
没有额外字体下载或装饰图片；使用本地楷体、宋体、serif fallback 和轻量 CSS 纸纹。

前台进入书本先看独立封面，点击封面或“翻开我们的故事”进入正文第一页面。原正文数量、pageId、photoId、顺序和翻页算法不变，封面不显示正文页码。
桌面打开动画约 650ms；手机淡出，减少动态效果时直接打开。3D 检测不通过则淡出，初始化异常直接打开，并有 700ms 完成兜底。

启动页仍保留，书本封面不会创建或修改 Audio。音乐播放进度与用户主动暂停状态由原 GlobalMusicPlayer 管理。
封面显示期间 Footer 在正常文档流中；手机正文仍保留已有 Footer 修复。没有修改 ICP 内容或链接。

## 图片与安全降级

配置只引用现有 photoId，不上传、复制、移动或生成 OSS 文件。
前台及预览优先使用现有 thumbnailSrc；旧照片没有缩略图时使用原 src。缩略图读取失败可退回既有原图；两者都失败隐藏图片区域，保留纯文字封面。前台不展示技术错误文字，后台提示重新选择。
不存在、隐藏或带未来软删除标记的照片安全降级；photoId 配置保留，以便恢复后下次读取自动显示。
独立封面未翻开时不渲染正文图片；配置照片封面的本地实测仅请求 1 张 thumbnail，正文图片等待翻开。
文字使用 textContent，不使用 HTML 插入。
